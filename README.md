## [HTTP-BROWSE](https://github.com/Kristoffer1122/http-browse)

HTTP-BROWSE is a little program that allows you to browse the web using HTTP requests. It is a simple command-line tool that can be used to fetch web pages and display their content in the terminal. **i guess its something like curl.**

## To build and use the browser:
1. Clone the repository:
   ```bash
   git clone https://github.com/Kristoffer1122/http-browse.git
    ```
2. Navigate to the project directory:
   ```bash
   cd http-browse
   ```
3. Build the project using the makefile:
   ```bash
    make build
   ```
4. Run the browser with a URL:
   ```bash
    ./bin/http-browse https://www.example.com
   ```
